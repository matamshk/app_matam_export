# نظام مواقيت الصلاة والتقويم الهجري - مأتم أبو صيبع الشرقي

تطبيق ويب حديث ومتكامل لإدارة وعرض مواقيت الصلاة والتقويم السنوي الهجري لمأتم أبو صيبع الشرقي بمملكة البحرين، مبني باستخدام تقنية Next.js وقاعدة بيانات SQLite/PostgreSQL مع Prisma ORM.

## المميزات الرئيسية
* **عرض تفاعلي لمواقيت الصلاة:** بطاقات ذكية لليوم الحالي مع مؤشر زمني والعد التنازلي الحي للأذان القادم.
* **التقويم الهجري الشهري:** جدول شهر متكامل يعرض المناسبات الدينية، رموز ملاءمة الزواج، ومسار القمر في برج العقرب.
* **قالب طباعة A4 فاخر:** صفحة مخصصة للطباعة خالية من الترويسات الإدارية ومصممة بأبعاد الطباعة الرسمية (210×297 مم) بدقة 300 DPI.
* **لوحة إدارة مدمجة:**
  * تسجيل دخول آمن للمسؤولين.
  * ضبط بداية الشهر الهجري (تعديل الأيام ±2) بشكل ديناميكي بحيث تتحرك المناسبات وتثبت أوقات الصلاة والميلادي.
  * إدارة المناسبات المركزية (إضافة، تعديل، وحذف).
  * إعدادات التواصل وهاتف الواتس أب.

## طريقة التشغيل المحلي (Development)
1. تثبيت الحزم:
   ```bash
   npm install --legacy-peer-deps
   ```
2. تهيئة وتوليد Prisma Client:
   ```bash
   node node_modules/prisma/build/index.js generate
   ```
3. تشغيل سكريبت التغذية الأولي لبيانات عام 1448 هـ:
   ```bash
   python scratch/seed_database.py
   ```
4. تشغيل خادم التطوير:
   ```bash
   npm run dev
   ```

## الانتقال للإنتاج (PostgreSQL Production)
1. قم بفتح ملف `prisma/schema.prisma` وقم بتعديل الـ `datasource` ليكون:
   ```prisma
   datasource db {
     provider = "postgresql"
   }
   ```
2. قم بتحديث الرابط في ملف `.env` ليشير لقاعدة بيانات PostgreSQL الخاصة بك:
   ```env
   DATABASE_URL="postgresql://username:password@localhost:5432/db_name"
   ```
3. قم بتشغيل التهجير لتأسيس الجداول في PostgreSQL:
   ```bash
   npx prisma migrate deploy
   ```
