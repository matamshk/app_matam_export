# مأتم - تطبيق الهاتف الذكي (Flutter Wrapper)

هذا المجلد يحتوي على تطبيق هاتف ذكي هجين (Hybrid App) تم إنشاؤه باستخدام **Flutter** لتغليف تطبيق الويب الخاص بـ **مأتم** وتشغيله داخل WebView.

## 🚀 الميزات المتاحة
1. **شاشة تهيئة الاتصال**: واجهة مستخدم مميزة لإدخال عنوان خادم بايثون ومطابقة الألوان الذهبية والرمادية للمشروع.
2. **حفظ الإعدادات**: يقوم التطبيق بحفظ عنوان الرابط تلقائياً باستخدام `SharedPreferences` بحيث لا تضطر لإدخاله في كل مرة.
3. **التشغيل بدون خادم (Static Mode)**: إمكانية تشغيل واجهات التطبيق محلياً بالكامل مباشرة من أصول التطبيق (Assets) في حال عدم توفر الخادم.
4. **تجاوز سياسة حظر HTTP**: مهيأ للسماح باتصالات النص الصريح (`usesCleartextTraffic`) للاتصال بالخوادم المحلية (`http://`).
5. **دعم زر الرجوع للوراء**: متوافق مع زر الرجوع الفعلي لهواتف أندرويد للتنقل داخل صفحات الموقع.

---

## 🛠️ متطلبات التشغيل
1. تثبيت **Flutter SDK** على جهازك (يمكنك تحميله من [موقع فلاتر الرسمي](https://flutter.dev) أو تثبيت أدوات إدارة مثل **Puro** أو **Sidekick**).
2. تهيئة بيئة تشغيل الهاتف (محاكي Android/iOS أو توصيل هاتف حقيقي وتفعيل وضع المطورين USB Debugging).

---

## 💻 طريقة التشغيل والتشغيل التجريبي

### الخطوة 1: تشغيل خادم بايثون الخلفي (Backend)
قبل تشغيل التطبيق في وضع الاتصال، تأكد من تشغيل خادم البيانات في المجلد الرئيسي:
* قم بتشغيل ملف `start_server.bat` في المجلد الرئيسي لتشغيل الخادم المحلي على المنفذ `8080`.

### الخطوة 2: تهيئة وتشغيل تطبيق فلاتر
افتح محرك الأوامر (Terminal) في هذا المجلد (`matam_flutter`) ونفذ الأوامر التالية:

1. **تحميل المكتبات البرمجية المطلوبة**:
   ```bash
   flutter pub get
   ```

2. **تشغيل التطبيق**:
   ```bash
   flutter run
   ```

## 🌐 ضبط الاتصال داخل المحاكي والهاتف

* **داخل محاكي أندرويد الافتراضي (Android Emulator)**:
  استخدم الرابط التالي للاتصال بالخادم الذي يعمل على نفس جهاز الكمبيوتر:
  `http://10.0.2.2:8080` (حيث يمثل العنوان `10.0.2.2` منفذ العودة الخاص بجهاز المضيف).

* **داخل محاكي iOS الافتراضي (iOS Simulator)**:
  استخدم الرابط المعتاد:
  `http://localhost:8080` أو `http://127.0.0.1:8080`.

* **عند التشغيل على هاتف حقيقي (Real Device)**:
  1. تأكد من اتصال هاتفك وجهاز الكمبيوتر الخاص بك **بنفس شبكة الـ Wi-Fi**.
  2. ابحث عن عنوان IP المحلي الخاص بجهاز الكمبيوتر الخاص بك (عن طريق كتابة `ipconfig` في موجه الأوامر بويندوز، مثل `192.168.1.105`).
  3. أدخل هذا العنوان في شاشة الاتصال بالتطبيق:
     `http://192.168.1.105:8080`

## 🔥 تهيئة وإعداد Firebase Firestore

لتفعيل التشغيل السحابي (Firestore Mode) بشكل كامل وحفظ البيانات مباشرة في قواعد بيانات جوجل السحابية بدلاً من الخادم المحلي:

1. اذهب إلى **[Firebase Console](https://console.firebase.google.com/)** وافتح مشروعك.
2. قم بإضافة تطبيق Android جديد للمشروع باسم الحزمة (Package Name): `com.example.matam_app`.
3. قم بتحميل ملف **`google-services.json`**.
4. ضع الملف المحمّل في المسار التالي داخل مشروع فلاتر:
   `matam_flutter/android/app/google-services.json`

بمجرد تشغيل التطبيق بعد إضافة الملف، سيقوم بالاتصال بقاعدة بيانات Firestore تلقائياً وسيتيح لك خيار التشغيل السحابي مباشرة!
